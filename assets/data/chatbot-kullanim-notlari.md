# Chatbot Güvenli Kullanım Notları

Bu proje için ileride eklenecek bilgilendirme chatbotu yalnızca genel bilgilendirme amacıyla kullanılmalıdır.

- Bot tanı koymamalıdır.
- Bot tedavi veya ilaç önerisi vermemelidir.
- Acil, kriz, istismar, ihmal veya tıbbi risk içeren durumlarda profesyonel destek, acil sağlık birimi veya ilgili resmi destek mekanizmalarına yönlendirme yapılmalıdır.
- Cevaplar genel bilgilendirme olarak sunulmalı, kişiye özel uzman değerlendirmesinin yerine geçmediği belirtilmelidir.
- Çocuk adı, okul adı, sağlık bilgisi veya başka hassas kişisel verilerin paylaşılmaması gerektiği hatırlatılmalıdır.
- Gerektiğinde kullanıcı iletişim formuna yönlendirilmelidir.
- API anahtarı veya gizli servis bilgileri frontend koduna eklenmemelidir.
